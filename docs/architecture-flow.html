Architecture Flow — Demo Studio

01 · Master flow — Demo Studio (Sources → Align → Rehearse)

%% 01 · Master flow — Demo Studio (Sources → Align → Rehearse)
flowchart TD
  U["USER adds sources<br/>[ask · Studio › Sources]<br/>in: video, images, PDF/DOCX/TXT, product URL, pasted brand text"]:::ask
  ING["store.add_*_source<br/>[FUNCTION · server/store.py]<br/>in: uploads / URL<br/>out: sources[] in data/demos/id/demo.json"]:::fn
  READBTN["POST /api/demos/id/read<br/>[FUNCTION · server/app.py]<br/>gate: ≥1 source · keys present or MOCK_LLM=1"]:::fn
  READ["READ phase (thread)<br/>[FUNCTION · orchestrator._read]<br/>Understand → Plan → voice sample → opening message<br/>see diagram 02"]:::fn
  SSE["GET /api/demos/id/events<br/>[FUNCTION · SSE, polls events.py every 0.35 s]<br/>out: progress / stage / status / message / phase_done"]:::fn
  OVER1["UI overlay<br/>'Reading your sources…'<br/>[FUNCTION · web/studio/align.js]"]:::term
  CARDS["Align: 4 cards<br/>Visuals · Facts · Persona & voice · CTAs<br/>[DATA · understanding.json + plan.json]"]:::data
  DOCK["USER speaks to the prompt dock<br/>[ask · text + optional files]"]:::ask
  ALIGN["Align loop<br/>[AGENT · claude-opus-5 → actions]<br/>see diagram 03"]:::agent
  APPR{"all 4 cards approved?<br/>[FUNCTION · demo.approvals]"}:::dec
  BUILD["BUILD phase (thread)<br/>[FUNCTION · orchestrator._build]<br/>Author → Voice → Rehearsal → Bundle<br/>see diagram 04"]:::fn
  OVER2["UI overlay<br/>'Building your demo…'"]:::term
  BUNDLE["bundle.json<br/>[DATA · data/demos/id/bundle.json]"]:::data
  PLAY["Rehearse: player<br/>[FUNCTION · web/player/player.js]<br/>see diagram 05"]:::fn
  FB["USER gives feedback<br/>[ask · Rehearse panel]"]:::ask
  FBA["POST /feedback → align agent (context=rehearse)<br/>[AGENT · claude-opus-5]<br/>revise('author'|'plan'|'understand') → rebuild"]:::agent
  LIB["Demos tab<br/>[DATA · list of data/demos/*/demo.json]"]:::data

  U --> ING --> READBTN --> READ --> SSE --> OVER1 --> CARDS
  CARDS --> DOCK --> ALIGN --> CARDS
  CARDS --> APPR
  APPR -- "no" --> DOCK
  APPR -- "yes · POST /build" --> BUILD --> OVER2 --> BUNDLE --> PLAY
  PLAY --> FB --> FBA -.->|"status building → ready, player remounts"| BUILD
  LIB -.-> U

02 · Read phase — Understand (Gemini looks, Claude reads) then Plan

%% 02 · Read phase — Understand (Gemini looks, Claude reads) then Plan
flowchart TD
  SRC["sources[]<br/>[DATA · demo.json]"]:::data
  ISV{"kind?<br/>[FUNCTION · understand.run]"}:::dec
  UPV["gemini.upload_file<br/>[LIBRARY · Gemini Files API]<br/>in: mp4/mov · out: file uri (poll until ACTIVE, ≤600 s)"]:::data
  SHOTS["shot list<br/>[AGENT · gemini-2.5-flash]<br/>in: whole video + VIDEO_PROMPT<br/>out: ShotsOut · start/end s, part, feature, quality 1-5 (≤60 shots)"]:::agent
  IMGS["image tags<br/>[AGENT · gemini-2.5-flash]<br/>in: batches of ≤12 images<br/>out: ImagesOut · description, angle, parts, quality"]:::agent
  IDS["assign ids<br/>[FUNCTION]<br/>sh01.., im01.. + source_id"]:::fn
  DOCS["sources.source_text<br/>[LIBRARY · pypdf / python-docx / httpx+bs4]<br/>in: pdf/docx/txt/url<br/>out: text with [page n] markers; PDFs also attached natively"]:::data
  FACTS["fact registry + brand + product<br/>[AGENT · claude-opus-5 · messages.parse]<br/>in: all documents + product hint (+ previous registry + revision instruction)<br/>out: FactsOut · facts with source ref/locator/quote, unknowns, brand"]:::agent
  FIDS["assign F001.. / U01.. · keep human edits<br/>[FUNCTION]"]:::fn
  UND["understanding.json<br/>[DATA]"]:::data
  PLAN["demo plan<br/>[AGENT · claude-opus-5]<br/>in: registry, shots, images, brand, URL (+ previous plan)<br/>out: Plan · persona, concerns, 6-10 segments, CTAs, voice brief, visual gaps, intake"]:::agent
  PVAL["drop refs that don't exist<br/>[FUNCTION · plan.run]<br/>fact_ids ⊆ registry · visual_refs ⊆ shots∪images"]:::fn
  PJ["plan.json<br/>[DATA]"]:::data
  SAMPLE["voice sample<br/>[LIBRARY · Gemini TTS (or gcloud/browser)]<br/>in: voice.sample_line · out: audio/hash.wav"]:::data
  OPEN["opening message<br/>[AGENT · claude-opus-5 · text]<br/>in: card summary · out: 3-5 sentences (template fallback on error)"]:::agent
  CONV["conversation.json<br/>[DATA] + SSE 'message'"]:::data

  ISV -- "pdf / doc / url / text" --> DOCS --> FACTS --> FIDS
  IDS --> UND
  FIDS --> UND
  UND --> PLAN --> PVAL --> PJ --> SAMPLE --> OPEN --> CONV

03 · Align loop — one prompt dock, one agent, structured actions

%% 03 · Align loop — one prompt dock, one agent, structured actions
flowchart TD
  MSG["USER message + optional files<br/>[ask · prompt dock or Rehearse feedback panel]"]:::ask
  ATT["attachments → sources<br/>[FUNCTION · app.align_message]<br/>files saved as role=product before the agent sees them"]:::fn
  BUSY{"is a stage running?<br/>[FUNCTION · orchestrator.is_running]"}:::dec
  WAIT["409 'Still working on the last change'<br/>[term]"]:::term
  HIST["conversation.json<br/>[DATA · last 12 turns sent as history]"]:::data
  AGENT["align agent<br/>[AGENT · claude-opus-5 · messages.parse]<br/>in: 4 cards summary, approvals, stage status, message, attachment list<br/>out: AlignOut · reply + actions[]"]:::agent
  APPLY{"action type<br/>[FUNCTION · orchestrator.apply_actions]"}:::dec
  A1["approve(card)<br/>[FUNCTION] approvals[card]=true → next-card prompt (template, no LLM)"]:::fn
  A2["edit_fact / remove_fact / resolve_unknown<br/>[FUNCTION] direct registry edit · author marked stale"]:::fn
  A3["set_ctas / set_voice<br/>[FUNCTION] plan.json patched · voice sample re-rendered"]:::fn
  A4["request_upload<br/>[term] note only — user must add files"]:::term
  A5["revise(stage, instruction)<br/>[FUNCTION] lowest stage wins if several"]:::fn
  A6["build<br/>[FUNCTION] only if all 4 approved"]:::fn
  A7["answer<br/>[term] nothing changes"]:::term
  REV{"which stage?<br/>[FUNCTION · _revise thread]"}:::dec
  R1["understand(instr) → plan<br/>approvals visuals+facts reset"]:::fn
  R2["plan(instr) → voice sample"]:::fn
  R3["author(instr)"]:::fn
  RB{"demo was ready, or context=rehearse?"}:::dec
  RBUILD["author(if stale) → voice → bundle<br/>status ready · phase_done build"]:::fn
  RALIGN["status align · phase_done revise"]:::term
  REPLY["reply appended to conversation<br/>[DATA] + SSE 'message'"]:::data

  MSG --> ATT --> BUSY
  BUSY -- "yes" --> WAIT
  BUSY -- "no" --> HIST --> AGENT --> APPLY
  APPLY --> A1
  APPLY --> A2
  APPLY --> A3
  APPLY --> A4
  APPLY --> A5 --> REV
  APPLY --> A6
  APPLY --> A7
  REV -- "understand" --> R1 --> RB
  REV -- "plan" --> R2 --> RB
  REV -- "author" --> R3 --> RB
  RB -- "yes" --> RBUILD
  RB -- "no" --> RALIGN
  A1 --> REPLY
  A2 --> REPLY
  A3 --> REPLY
  A7 --> REPLY
  ATT -.->|"files but no revise action → revise('understand')"| A5

04 · Build phase — Author (validated) → Voice → Rehearsal → Bundle

%% 04 · Build phase — Author (validated) → Voice → Rehearsal → Bundle
flowchart TD
  GO["POST /api/demos/id/build<br/>[FUNCTION] gate: all 4 approvals true"]:::fn
  AUTH["script draft<br/>[AGENT · claude-opus-5 · messages.parse]<br/>in: plan, registry, shots, images, brand (+ previous script + instruction)<br/>out: ScriptOut · segments › lines {text, visual, fact_ids, card}, checkin, deeper, closing, intake q1/q2"]:::agent
  VAL["grounding validator<br/>[FUNCTION · author.validate]<br/>fact_ids ⊆ registry · visual ref exists · NUMBERISH or CLAIMISH text with no fact id → unverified"]:::fn
  ISS{"issues > 0?"}:::dec
  FIX["one repair pass<br/>[AGENT · claude-opus-5]<br/>in: draft + issue list · out: full script"]:::agent
  VAL2["re-validate<br/>[FUNCTION] remaining offenders stay unverified → excluded from voice & bundle, listed on Facts card"]:::fn
  SJ["script.json<br/>[DATA] ids seg-L1.., version++"]:::data
  PROV{"tts provider?<br/>[FUNCTION · voice.provider_for]<br/>gemini · gcloud · browser (no key)"}:::dec
  TTS["render every line<br/>[LIBRARY · Gemini TTS / Cloud TTS]<br/>cache key sha1(provider|voice|text) → audio/*.wav|mp3<br/>0.25 s pause · stop after 4 failures"]:::data
  BROWSER["voice_provider=browser<br/>[term] player speaks with Web Speech"]:::term
  QGEN["likely customer questions<br/>[AGENT · claude-opus-5]<br/>in: product, persona, concerns, fact claims · out: N questions (settings.rehearsal_questions, default 12)"]:::agent
  QA["answer each via qa.answer<br/>[AGENT · claude-opus-5 + FUNCTION validator]<br/>see diagram 05 · one paid call per question"]:::agent
  COV["coverage = answered / N · gaps list<br/>[FUNCTION] → rehearsal.json"]:::fn
  BUN["bundle.build<br/>[FUNCTION · bundle.py]<br/>in: demo, understanding, plan, script<br/>out: bundle.json · segments with media URLs, audio, cards, CTAs, facts, unknowns; version++"]:::fn
  READY["status ready · SSE phase_done build<br/>[term]"]:::term

  GO --> AUTH --> VAL --> ISS
  ISS -- "yes" --> FIX --> VAL2 --> SJ
  ISS -- "no" --> SJ
  SJ --> PROV
  PROV -- "gemini / gcloud" --> TTS --> QGEN
  PROV -- "browser" --> BROWSER --> QGEN
  QGEN --> QA --> COV --> BUN --> READY

05 · Runtime — the player (web/player/player.js) and grounded Q&A (server/agents/qa.py)

%% 05 · Runtime — the player (web/player/player.js) and grounded Q&A (server/agents/qa.py)
flowchart TD
  START["USER clicks Start<br/>[ask]"]:::ask
  Q1["speak intake q1<br/>[LIBRARY · bundle audio, else /run/tts, else Web Speech]<br/>'your name and why you're interested'"]:::data
  L1["listen ≤10 s<br/>[LIBRARY · Web Speech recognition]<br/>mic denied or silent → typed fallback input"]:::data
  P1["parse name + focus topics<br/>[FUNCTION · parseName / parseFocus — regex + chip/segment keywords, NO LLM]"]:::fn
  Q2["speak ack + intake q2<br/>'anything specific, or get going?'"]:::data
  L2["listen ≤10 s → isGetGoing?<br/>[FUNCTION]"]:::fn
  PLAN["order segments<br/>[FUNCTION · planSegments]<br/>welcome first · focus topics next · rest in bundle order"]:::fn
  LINE["play line<br/>[FUNCTION] showVisual: seek video to start…end, or image Ken Burns · card · cite 'sources: F..'<br/>speak: server audio else browser TTS"]:::fn
  CHK["check-in question<br/>[LIBRARY · audio] then chips"]:::data
  WAIT["waitFor 15 s countdown + auto-listen 8 s<br/>[FUNCTION · interpretReply — regex, NO LLM]<br/>yes/continue · deeper · question · timeout"]:::fn
  DEEP["deeper lines (2-3, pre-authored)<br/>[FUNCTION]"]:::fn
  QIN["question text<br/>[ask · voice or 💬 typed]"]:::ask
  QA["POST /api/demos/id/run/qa<br/>[AGENT · claude-opus-5 · messages.parse]<br/>in: question, last 8 turns, profile, registry, visuals, CTAs<br/>out: QAOut · answer, fact_ids, visual_ref, escalate, cta, answered"]:::agent
  QV{"valid?<br/>[FUNCTION · qa.answer]<br/>fact_ids ⊆ registry AND (answered OR no number/claim words)"}:::dec
  SPEAK["speak answer · seek to visual · card 'Sources for that answer'<br/>[FUNCTION]"]:::fn
  NOG["'I don't want to guess…' · escalate=question<br/>[FUNCTION] question appended to understanding.unknowns (origin runtime)"]:::term
  CONF["'Did that answer it?' → chips yes / not quite (20 s)<br/>[FUNCTION]"]:::fn
  RES["resume: next segment if at check-in, else same line<br/>[FUNCTION · resumeAfterQA]"]:::fn
  CLOSE["closing lines → CTA chips from bundle.ctas + Not yet<br/>[FUNCTION · closeFlow]"]:::fn
  HAND["handoff summary<br/>[FUNCTION · intentScore] → POST /run/session → sessions/s_*.json"]:::data

  START --> Q1 --> L1 --> P1 --> Q2 --> L2 --> PLAN --> LINE
  LINE --> CHK --> WAIT
  WAIT -- "continue / timeout" --> LINE
  WAIT -- "deeper" --> DEEP --> WAIT
  WAIT -- "question" --> QIN --> QA --> QV
  QV -- "yes" --> SPEAK --> CONF --> RES --> LINE
  QV -- "no" --> NOG --> CONF
  LINE -- "last segment" --> CLOSE --> HAND
  QIN -.->|"interrupt at any moment cancels speech (run token)"| LINE
