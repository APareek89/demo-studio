The official pack supports two reviewed prices and a set of Technology-only features, but it does not make every commercial or safety conclusion safe. The runtime now states the known rows and declines the unsupported label or scope.

## Findings closed in this gate

- **P1 — the 34.8 MB brochure exceeded the primary reader's request envelope:** an oversized request may now use only an explicit, source-validating human-reviewed fact manifest. It cannot fall through to guessed extraction.
- **P1 — nearby truths answered different compound intents:** variant pricing, performance, quattro, dimensions and branded features now use narrow ordered fact paths. The current product name replaces a leaked hard-coded Harrier label.
- **P1 — missing scope could be manufactured:** ground clearance and per-variant ADAS fail closed; pictures cannot prove fitted equipment; synthetic EMI cannot be guaranteed; and “cheapest” states the reviewed line-up and prices without assigning a permanent label.
- **P1 — voice completion failed under a provider window:** partial work is checkpointed, but ready still requires every FAQ and filler. The final bundle has complete audio.
- **P1 — parallel voice workers mutated circuit state concurrently:** the shared provider circuit breaker is locked; the observed `dictionary changed size during iteration` failure is covered by regression and did not recur.
- **P1 — a poll could read a JSON artifact mid-write and reset live visual state:** stage artifacts are now published by atomic replacement. The full mocked pipeline passed after the fix.
- **P2 — answered gaps could remain stale or duplicate the extraction list:** newly answerable runtime gaps clear themselves, and near-identical extraction gaps are not appended again.
- **P2 — visual concurrency coverage depended on machine timing:** the free visual test now holds the first mock job at an explicit barrier while checking duplicate-build, input-lock and skip behaviour.
