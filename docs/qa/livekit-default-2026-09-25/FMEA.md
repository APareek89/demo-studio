# FMEA — default LiveKit transport

Scope: transport selection in both player entry points, token/room facade, shared client deadlines, local launcher and AWS TLS/relay deployment. Product context: PRD's one voice, unchanged Build/Align and evidence owners, interruption recovery, reviewed image before speech, incremental sessions and public feedback demo. System context: one application worker and local storage on a913MiB EC2 instance; two hosted rooms, existing operator boundary, no paid release QA.

The feature scan walks public playback, Rehearse, local launch, room creation/use/destruction, hosted relay and rollback. Deployment acceptance is a separate gate; implementation tests do not prove network reachability or acoustic quality.

Fixed items are retained to show what the review caught. Hosted identity/relay/renewal gates completed: actual edge41/41, hosted RTC32/32, public RTC9/9, certificate-sync success and enabled timer. Directory traversal and AF_NETLINK startup failures were recovered and fixed before app cutover. The [AWS receipt](../../aws/release-livekit-2026-09-25.md) records these actual results and the12-category infrastructure review. No confirmed P0 code finding. Residual two-room capacity, one-hour visit, explicit reconnect and physical-device/network variation are disclosed limits rather than silent promises.

Race/state: publication changes during join, navigation, late joins, microphone generations and stale error owners. Resource exhaustion: body/fragment/queue/room/rate bounds. Security: origins, scoped grants, proxy identity, private secrets and unchanged operator routes. Data integrity: no demo migration/rebuild, existing incremental saves and source/data hashes. Observability: systemd/logs, runtime errors and dated receipts; no new automated alerting is claimed. Scale/load: small-host two-room limit, no fleet-scale acceptance. Billing: mock/blank-key/socket isolation and no duplicated provider turn. Retry/idempotency: no semantic replay and definite room disposal. Configuration drift: capability/SDK/TLS/local-hosted distinctions and both entry points. PRD edges: one voice, image before speech, controls, typing, Rehearse and unchanged approval/grounding gates.
